# 统一登录、RBAC 与设备管理验收

2026-09-30，Windows x64，中文目录 `D:\项目\SuperDsh`。本次仅在临时账号、Home、数据库和模型夹具上验证；当前 15174 服务及既有用户数据、DeepSeek 配置未升级或改写。

## 实现

| 范围     | 实现入口与行为                                                                                                                                    |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| 身份     | 桌面平台登录独立于 DeepSeek；系统浏览器授权码 + PKCE，凭据留在主进程；账号空间按服务地址和稳定用户 ID 隔离，重启切换。                            |
| RBAC     | 只有 `admin`、`member` 两个锁定内置角色，允许自定义角色和多角色并集；权限不绕过资源归属，管理员无法访问他人内容。                                 |
| 登录撤销 | 15 分钟 access、30 天可轮换 refresh；网页登录使用 HttpOnly Cookie，安卓使用 Keystore；HTTP、WebSocket、预览、附件、授权码和手机 QR 绑定登录会话。 |
| 管理     | 用户搜索与分页、角色分配、禁用、软删除/恢复、发起恢复、设备白名单运维、持续封锁/恢复、模型管理、审计与登录记录。                                  |
| 桌面远程 | Core 管理唯一 Connector 和 API v2；通过真实 Harness 的 RuntimeBridge 保留执行队列与手机协议，产品 UI 管自己的设备、聊天、文件和终端。             |
| 模型     | 三种兼容推理协议、服务端 AES-GCM 加密供应商 Key、固定平台代理和流式取消；个人模型仍保存在执行设备，本次没有外部模型消费。                         |
| 导入     | 平台导入只复制到空目标，排除授权、Key、环境变量、`.credentials.yaml` 和设备绑定；保留本地空间。                                                   |

当前源码入口与启动命令见 [README](../README.md#三端联调)、[服务端说明](../apps/server/README.md)。固定上游子模块未修改；RuntimeBridge 窄入口由受控产品补丁生成。
