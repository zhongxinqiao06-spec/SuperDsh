# 三个办公助手升级记录

范围：2026-10-17 至 2026-10-19，Windows 中文仓库路径、Node 24、Yarn 4.18。本轮面向单企业试用，保留原智能体 ID、已冻结会话及用户修改；不包含企业多租户或操作系统沙箱。

## 已实现

- Excel 办公助手：CSV/XLSX 多文件、多工作表、表头和字段映射；清洗、去重、筛选、排序、拼接、关联、分组和交叉统计；精确十进制计算、受控公式及其缓存结果、原生可编辑图表。来源、计算口径和异常记录随成果保留。缺少成本不计算利润，不混加不同币种。
- PPT 演示助手：公司介绍、培训、方案及汇报；文本、知识资料、表格和图片组合；模板按实际页面关系和区域映射，保留原生标题、正文、表格、图表及图片。预检过长中文、拥挤表格、模板不支持对象和缺失素材；生成后尝试实际 PDF 渲染，记录字体/渲染诊断并缓存预览。预览失败保留可编辑文件，允许明确重试。
- 企业知识助手：TXT、Markdown、DOCX、CSV、XLSX、文字型 PDF 独立解析；保留标题、段落、页码、工作表及行号。固定 BGE ONNX 与 Qdrant 稠密/关键词 RRF 检索，独立外部 Embedding 配置，逐文件状态和重试。服务端验证引用 ID、来源权限和逐字摘录；资料内容始终作为数据处理。
- 通用流程：显式输入检查、持久化方案、现有 Harness 用户确认、执行与成果版本。管理网页和桌面主聊天共用公开契约，展示方案、原文和成果。没有隐式演示资料回退；修改生成新版本。
- 配置治理：智能体、知识库、技能、工具继续独立管理；新版示例仅升级未修改记录，自定义配置保留，已删除记录不复活，支持显式复制新版示例。发布前检查输入和工具配置。

## 本轮修复的关键问题

- 确认绑定账号、会话、调用、输入哈希、方案版本和挑战值；旧确认及模型伪造批准无效，同一批准不重复产生成果。
- 修订、失败回写与成功执行并发时，不能覆盖已完成方案。确认等待不消耗生成预算，主动取消与执行超时分别显示。
- PPT 模板检查跨 Worker 只传可序列化描述，不传 ZIP 对象；超过三份知识材料和重新排序模板页均可处理。
- 生成文件先写存储、后提交 SQL；未提交成果及预览不可通过附件接口读取。上传不能覆盖成果、预览或内部输入的保留 ID；失败后显式重试复用原成果身份。
- 外部 Embedding 必须是部署侧 `SUPERDSH_KNOWLEDGE_EMBEDDING_TRUSTED_ORIGINS` 批准的 origin，保存与全局重建同时检查 `models.manage` 和 `agents.manage`。网络内网许可不能代替资料外发许可；撤权或移除信任后不发送资料和 Key。
- 引文校验对大量未闭合引号保持有界处理，不能阻塞 Node 主线程。旧资料未记录原文位置时不伪造页码，需管理者明确重解析。

- 扩展清单、工具 Schema、配置密钥、安装/健康检查/启停/版本回滚及历史引用进入统一管理；现有工具保留 ID，通过适配器注册。Node、Python 与 MCP 工具不新增执行队列。

- 空闲会话可显式切换助手；历史方案、成果和证据保留原绑定版本。停用资料后旧证据访问仍被拒绝，跨账号不能读取。
