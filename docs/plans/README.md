## 维护约定

- 一个主题只有一份规则正文，其他文档通过链接引用；应用 `AGENTS.md` 是开发规范的强制入口。
- 需求变化同步更新对应产品文件；字段或关联变化同时更新数据字典，不能先把目标写成已实现。
- 交付状态附实际证据与限制，区分静态检查、受控测试、真实供应商和原生客户端；未验项不能随文档清理消失。
- 运行日志、截图、测试 Home、迁移包和过程文件放 `.superdsh-work/web-admin-validation`；不重新塞回计划目录，也不纳入生产镜像。
