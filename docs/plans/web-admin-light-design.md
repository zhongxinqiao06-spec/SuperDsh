琥珀深阶渐变用于重点按钮、当前导航和当前步骤；浅杏渐变用于场次、选项和分段选中态。文字操作使用独立的可读强调色。两套产品共享字体、间距、控件和弹窗结构。深色与跟随系统仍是用户偏好，产品切换不改写偏好；娱乐深色主按钮仍使用白字，弱选中态使用暗琥珀底与浅杏文字。媒体画面本身可保留深色监视器背景。

## 琥珀精修版公共规范（2026-11-16）

- 十阶橙色集中在 `tokens.css` 的 `--orange-50` 至 `--orange-900`：`#FFFAF1 / #FFF2DB / #FFE1AD / #FFC276 / #F49E41 / #E17A25 / #B95A19 / #974410 / #763510 / #55250D`。
- 组件只消费 `--primary-fill`、`--primary-fill-hover`、`--selection-fill`、`--selection-ink`、`--nav-active-fill` 等语义变量。主操作 135° 渐变，悬停加深；弱选中态 110° 渐变；工作区右上方只保留低透明度暖光。Element Plus 和传送至 body 的弹层共享同一映射。
- Geist 与微软雅黑 / 苹方回退；页面标题 24px、分区 18/26、正文 15/24、剧本 16/30、导航 14/22、辅助 13px。现有 `AppIcon` 统一为 18px、1.5 线宽，保留正式星桥标识。
- 页边距 32px、分区 24px、字段 16px、控件间距 8px、面板内边距 24px；窄屏沿用 16px 与至少 44px 的主要触控尺寸。卡片只用薄描边和极轻阴影，透明工具栏不继承卡片阴影。
- 主稿与场次双栏约 61:39，场次目录收紧为 56px 行高；有正文且无待审建议时省去重复的入门说明。选段操作使用独立白色轻浮层。作品卡无封面时使用浅杏底和真实片名，不填入参考图的车站照片。
- 参考元素来自 [Linear](https://linear.app/now/behind-the-latest-design-refresh)、[Raycast](https://www.raycast.com/blog/a-fresh-look-and-feel)、[Frame.io](https://frame.io/features/review-and-approval)：细层级、上下文操作、媒体与元数据的分区。参考图中的示例菜单、摄影和虚构时长不进入生产数据。

本轮浏览器验收使用正式 Vue 页面、合成接口和临时浏览器上下文，不读写真实账号或工程。过程证据在 `.superdsh-work/web-admin-validation/amber-implementation-20261116`。主操作常态、悬停、步骤与场次选中态均检查 101 个渐变插值点，对比度至少 4.5:1；既有下拉输入层、固定弹窗底栏、焦点、草稿与只读检查继续保留。

本轮最终结果：30 项独立浏览器用例、37 个文件的 158 项前端单测、应用和测试 TypeScript、143 个 Vue 模板、修改文件的 ESLint/Prettier、所有权与架构检查及前端生产构建通过。旧 `apps/admin` 的 746 个已跟踪文件哈希变化为零。新测试服务 5188/5189 已退出，用户前端 5175 保持运行。构建仍有大于 500 kB 的依赖分块提示；没有将样式验收描述成真实后端或媒体生成验收。
