# 星桥页面设计

本文是星桥办公、星桥娱乐及共享管理后台的统一视觉与交互规范，适用于 `apps/web-admin` 的 Vue 正式页面、公共组件、弹窗、抽屉和公开入口。以当前浅色双产品方案为准，不再沿用娱乐默认黑色、管理行操作收进“更多”、主列表分页紧随短表等旧方案。

开发分层、运行与测试目录遵循[开发规范](开发规范.md)；产品边界、执行及权限遵循[整体架构](整体架构.md)。菜单和业务范围分别见[星桥办公需求与设计](星桥办公/需求与设计.md)、[星桥娱乐需求与设计](星桥娱乐/需求与设计.md)。本文件规定页面如何呈现和操作，不重复维护接口、表结构、供应商配置或阶段交付清单。

## 1. 设计依据与适用顺序

当前娱乐管理端采用象牙白工作区、暖白工作面与铜橙；办公采用珍珠白工作区、白色工作面与钴蓝。两端共享布局骨架和组件尺度，以主操作、选中态和品牌区分产品。浅色、深色和跟随系统是独立用户偏好，切换产品不能改写该偏好。

规则优先级为用户最新确认、本文件、当前公共组件契约；历史设计稿只解释来源。视觉规范与实现有差异时记录并修复，不把代码现状自动视为新的设计决定。

## 2. 色彩、排版与空间

### 2.1 产品主题

| 语义          | 星桥娱乐浅色              | 星桥办公浅色         |
| ------------- | ------------------------- | -------------------- |
| 工作区背景    | `#FCFAF7`                 | `#F7F8FA`            |
| 工作面 / 侧栏 | `#FFFDFB` / `#FAF6F1`     | `#FFFFFF`            |
| 分隔线        | `#E6DDD4`                 | `#E3E7EE`            |
| 正文          | `#302820`                 | `#202632`            |
| 辅助文字      | `#6F645D`                 | `#667085`            |
| 主操作        | `#B45A2A → #94411B`，白字 | `#3659E3`，白字      |
| 弱选中态      | 浅杏底与深琥珀文字        | `#EDF1FF` 与钴蓝文字 |

娱乐十阶橙色依次为 `#FFFAF1 / #FFF2DB / #FFE1AD / #FFC276 / #F49E41 / #E17A25 / #B95A19 / #974410 / #763510 / #55250D`。深阶承载白字主操作；当前导航采用浅杏底、深铜文字和左侧细线。浅阶也用于场次、选项和分段选中态。主操作采用铜橙渐变，悬停加深；弱选中态采用 110° 渐变。工作区可保留低透明度暖光，卡片使用薄描边和轻阴影，避免大片高饱和背景和多层边框。

颜色的实现来源是 [`tokens.css`](../../apps/web-admin/fronted/src/assets/styles/tokens.css)。组件消费 `--primary-fill`、`--primary-fill-hover`、`--selection-fill`、`--selection-ink`、`--nav-active-fill`、`--background`、`--card`、`--border` 等语义变量，不复制十阶色值。Element Plus、原生控件及传送到 `body` 的菜单、弹窗和下拉列表均继承当前产品主题。

深色主题分别使用蓝灰办公工作面、暗中性娱乐工作面，并保持可读的文字、边框和焦点。娱乐深色主按钮继续白字，弱选中态使用暗琥珀底与浅杏文字。媒体监视器可以保留深色衬底，文件页可以保留真实纸面；这些局部内容不改变整站主题。状态同时使用文字和图形，不能只靠颜色区分成功、危险或当前步骤。

### 2.2 公共尺度

| 项目        | 当前标准                                                                                          |
| ----------- | ------------------------------------------------------------------------------------------------- |
| 字体        | Geist，中文回退微软雅黑、苹方及系统无衬线；时间码等必要内容使用等宽字体。                         |
| 字号 / 行高 | 页面标题 24px；分区 18 / 26px；正文 15 / 24px；剧本 16 / 30px；导航 14 / 22px；辅助文字 13px。    |
| 内容边距    | 桌面页面 32px；面板 24px；窄屏页面与面板 16px。                                                   |
| 间距        | 分区 `--layout-gap` 24px；字段 `--field-gap` 16px；控件 `--control-gap`、标签 `--label-gap` 8px。 |
| 控件        | 常规 40px，紧凑 32px；窄屏主要操作触控区域至少 44px。                                             |
| 圆角        | 控件 8px、卡片 10px、弹窗 14px。                                                                  |
| 导航        | 桌面侧栏 248px、顶栏 60px；窄屏使用导航抽屉，保留完整入口和层级。                                 |
| 图标        | 复用 `AppIcon`，常规 18px、线宽 1.5；品牌复用 `StarbridgeMark`。                                  |

纵向分区用 `.stack`，字段组用 `.form-stack` 或 `form.stack`，标签与控件用 `.field`，操作行用 `.toolbar` 或 `.dialog-actions`。间距由父容器的 `gap` 管理，不能再给每个子项叠加同等 `margin`。页签与其内容、筛选与表格、说明与按钮之间也遵循这些尺度。

公共页面采用紧凑无衬线标题，不以巨大标题、胶囊按钮堆叠或多层卡片制造层级。长说明在原位展开；隐藏部分内容必须有明确的展开入口，不能静默截断关键错误或禁用原因。

管理详情页沿用确认图的象牙白纸面、墨色标题和细分隔线。娱乐的对象名称、表单分段和弹窗标题用宋体，字段、按钮与说明用无衬线字体。对象详情页头右侧使用同一份本地胶片图片，深色与办公主题采用各自的色面。连接信息和套餐用量桌面并列、窄屏堆叠；只读键值按行对齐，长标识可换行。短字段随可用宽度并排，密钥与长地址占整行。弹窗固定标题和操作区，正文单独滚动。

## 3. 页面骨架与导航

### 3.1 共享控制台

办公和娱乐使用同一套控制台及服务端 RBAC 菜单，只展示当前产品和账号有权访问的一、二级入口。一级分组、展开标识、二级缩进和当前项状态明确；父级展开与子页选中分别表达。长菜单文字可读，折叠后图标入口具有可访问名称。具体菜单项与角色分配在各产品需求文档维护，不按样图硬编码。

产品切换、外观和账号操作保留稳定位置。切换时处理未保存编辑，再读取目标产品菜单、模型和资源；旧请求不能把上一个产品内容写回当前页面。切换后失去权限的入口不继续展示可操作状态，服务端仍负责最终授权。

### 3.2 管理列表

列表按“页面名称 → 工具栏 → 数据区 → 内容区底部分页”组织：

1. `PageHeader` 只留页面名称，删除重复的功能介绍、入口提示和记录计数。权限不足、连接失败、校验与空数据引导保留在对应区域。
2. `FilterBar` 集中搜索、筛选和新增、导入、刷新等页面级动作。聊天与多模态模型页先按供应商连接展示套餐、额度来源、密钥状态和已配置模型，下方保留模型搜索和新增配置。查看、替换或清除已保存的 API Key 时单独确认当前管理员密码。设置页的编辑按钮放在对应设置项旁。
3. `ManagementList` 容纳独立滚动的数据区；`DataTable` 或现有具备专用能力的表格消费相同样式。主分页留在内容区底部，四条数据也不跟着短表上移；数据较多时最后一行完整可见，切页回到列表顶部。
4. `ManagementPagination` 左侧显示总数与当前范围，右侧显示每页条数和翻页。弹窗、卡片与子列表使用自身分页，不借用主页面分页。空态、无匹配结果与加载失败分别表达。

管理记录的动作通过 `RowActions` **直接显示**。模型行显示编辑、只读检测、设为默认；默认项显示清除默认。智能体按权限与发布状态显示编辑、试用、发布检查、发布或取消发布、删除。其他列表沿用相同原则，权限判断、禁用理由和处理方法由业务提供。桌面操作列按实际按钮数留宽，窄屏优先已有卡片布局，文字动作可以换行。

**工作台历史会话保留行末省略号菜单**，重命名、置顶、归档、删除在展开后操作；不把四个动作常驻堆在每个标题下。工作台项目管理动作放在记录名称下方。上述例外不改变管理表格的直接操作规则。

### 3.3 信息密度

优先展示名称、状态、来源和用户当前要处理的问题。日期有统一格式；金额带单位并对齐；文件优先显示人可读类型。UUID、内部枚举、模型标识、原始 JSON 不作为主标题，必要时在详情和复制入口保留。工程修订、生成任务及文件来源仍是真实数据，不能为了整洁而丢失追溯能力。

首次加载显示必要骨架或状态；后台刷新保留现有内容，不整页闪空。列表和按钮的加载状态不改变布局宽度。错误应说明当前失败的操作和可用恢复入口，不以空列表或“已完成”掩盖失败。

## 4. 公共组件、表单与浮层

| 组件或归属                                                            | 页面共同遵守的职责                                                                               |
| --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `PageHeader`、`FilterBar`                                             | 分离页面名称、筛选和页面操作，避免重复标题与散落的刷新按钮。                                     |
| `ManagementList`、`DataTable`、`RowActions`、`ManagementPagination`   | 统一列表视区、数据层级、直接动作、忙碌禁用及分页归属。                                           |
| `ManagementDialog`                                                    | 编辑或只读弹窗，固定标题、关闭与底栏，正文单独滚动；统一提交、错误、脏状态与关闭行为。           |
| `AppDrawer`                                                           | 工作区补充编辑与 AI 面板；标题和 footer 参与正常布局，正文为主滚动区；领域草稿不因收起抽屉丢失。 |
| `ScrollPanel`                                                         | 块内目录、检查器与成果栏：标题、页签和操作留在独立区域，仅正文滚动；保持名称、焦点和键盘可达。   |
| `FormSection`、`LongTextField`、`StringListEditor`、`ResourceChoices` | 字段分组、长文编辑、逐项输入和资源检索；不替代领域表单状态。                                     |
| `AiTextComparison`、`ExpandableText`                                  | 复用前后对照、候选编辑和长说明原位展开，避免原始字典或多层小滚动框。                             |
| `ResourceStatus`、`DateTime`、`SettingsCard`                          | 状态、时间和设置动作使用相同语义与规格。                                                         |

样式职责依次为 `tokens.css` 的语义变量、`base.css` 的基础排版与显式原生控件、`element.css` 的组件库映射、`layout.css` 的公共布局，以及领域样式的特有结构。页面不复制控件皮肤，不增加宽泛的 `input/select/textarea` 祖先选择器，也不靠叠加 `!important` 修补继承问题。

### 表单与按钮

- 标签与输入一一关联，必填、选填、格式和错误就近说明。占位文字不能替代标签。短文本合理增长，长文本可展开集中编辑；不能把所有长要求固定压成数行。
- 原生文本、数字、下拉、文本域及可见文件输入显式使用 `.native-control`，紧凑控件追加 `.native-control--small`。范围滑块、复选框和专用编辑器按各自语义处理。Element Plus 内层搜索 input 保持透明无边框，焦点反馈由外壳承载。
- 一个任务区域明确一个主要动作，次要操作使用较轻权重。危险操作写明对象与影响并确认；提交期间禁用同一动作，禁止重复创建任务。禁用不是解释，关联原因应在附近可读。
- 智能体等复杂编辑器按基本信息、行为规范、资源关联、示例与发布等实际职责分区，同一草稿跨分区保留。校验失败定位对应区块和字段，保存失败保留输入。
- 资源关联提供搜索、已选数量和已选摘要；不要同时挤放数个很矮的滚动列表。业务专属内容仍由领域组件承载，不制造万能 JSON 表单。

### 滚动与关闭

- 长弹窗和抽屉只让正文承担主纵向滚动。标题、关闭、错误反馈与确认操作始终可达；滚动条不能与关闭按钮争用空间。
- 块内滚动同样使用“固定标题/页签 → 可滚动正文 → 必要底栏”，通过公共 `ScrollPanel` 装配；不能把标题包进滚动正文，也不能用悬浮标题遮住第一条内容。已有资源选择、场次目录等标题在滚动区外的结构继续保留。
- 全站滚动条外观集中在 `scrollbar.css`，尺寸与颜色来自主题变量。采用透明轨道、圆角细滑块和悬停增强；Chromium 去掉系统上下箭头，其他浏览器保留标准细滚动条回退。文本域、弹窗、列表和 Element Plus 自绘滑块遵守同一配色，键盘、滚轮和触摸能力保持。
- 底部操作使用公共 footer，不能在正文上叠一块 sticky 区域遮住最后的复选框、输入或错误。手机按钮允许完整换行，并考虑安全区。
- 文本详情优先原位折叠，当前对象编辑与目录分开；保留合理的代码、时间线等专用滚动，不制造“弹窗 → 卡片 → 每个文本框”多层滚动。
- 打开、切换和关闭都保留适用的草稿保护。收起导演抽屉不代表放弃任务；放弃建议、终止对话和取消媒体制作是不同动作。
- 媒体预览使用公共只读弹窗，显示工程版本，画面保持原比例并限制高度；当前 `StudioMediaPreview` 限制图片和视频为 `65dvh`。竖屏视频不能把关闭按钮推到页面末尾；关闭时卸载播放器，预览、下载继续走原授权接口。

## 5. 官网、登录与系统选择

官网用于说明产品用途，默认娱乐，可匿名切换办公。保留 `/#/` 与 `/#/website`；办公展示态使用产品查询参数，例如 `/#/?product=office`。切换参与浏览器历史，刷新、分享、前进和后退恢复对应版面，不要求先登录或改写账号偏好。

| 入口       | 展示与交互                                                                                                                                                                                                                 |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 娱乐官网   | 橙色主导、暖白与杏色分层的五章节展示：灵感开场、创作类型、八步制作流程、创作优势、开始创作。桌面一章一屏，原生滚动吸附；手机长章自然增高。公开四镜演示可以选镜；“进入创作台”连接登录后的创作中心。                         |
| 办公官网   | 使用珍珠白、钴蓝和报告信息层级。图表、月度明细和 CSV 下载来自同一公开样表：38.6、41.6、48.4 万元，季度合计 128.6 万元。示例下载与私人交付明确区分。                                                                        |
| 系统选择页 | 中性底色，娱乐在左、办公在右，手机娱乐在前；整卡可操作，名称、用途、进入动作和键盘焦点可见。                                                                                                                               |
| 登录及续接 | 桌面左侧为镜湖胶片剧照，右侧为暖色表单；手机将剧照裁为顶幅。边光沿胶片移动，减少动态偏好时定格。下划线输入与居中粗体铜橙按钮用于账号登录和开放注册。双资格账号进入系统选择，单资格直达对应工作台；合法深链登录后优先恢复。 |

娱乐首屏使用宋体标题、橙色主按钮和同构图的分镜与成片对照。访客可拖动分界线，或依次查看剧本、分镜和成片画面。胶片的画格与齿孔沿样片边缘自动走片。后景四张画片以不同方向和节奏缓缓移动，主样片和作品入口的点击位置保持稳定。右下角的动效开关可同时暂停画片与胶片，开启减少动态偏好时背景定格，样片由访客逐步切换。桌面将主样片放在前景，故事短片从左下方展开，角色动画和雨夜竖屏画片从上方两侧露出，右下方以剧照收尾。手机将整组画片排在标题与操作下方。三类作品的名称与可点击区域保持可见，可分别打开大图。展示使用公开的原创示意素材。办公官网继续使用产品界面、静物及数据图表。中英文、隐私说明、跳至正文、多端展示和导航入口保留。

后四屏继续复用根层 `--showcase-*` 配色和宋体标题。创作类型以宽银幕、角色设定稿和雨夜竖幅叠放展示，胶片缩略图可切换故事镜头。制作章把八步分为四组，访客可选步骤、暂停播放头或手动切换四个试拍镜头。优势章用同一角色的中景和近景比较候选，并以角色照、声纹和剧本批注展示复用与定稿。收尾用雪山、分层薄雾和进入创作台的按钮。动效开关在五屏间共用，开启减少动态时由访客逐步操作。公共页距、标题、页脚和画框在 `website/studio-chapters.css`；三类作品、制作手记及镜头对照各自集中维护。短屏与手机保持原生滚动，可完整访问长章中的控制项和页尾。

分屏只有一个原生纵向滚动容器，不拦截滚轮；侧边章节导航、PageUp/PageDown/Home/End、减弱动画设置均可用。滚动吸附章节不继承旧官网的顶部锚点补偿。短屏与手机使用 proximity，长章中的卡片和页尾必须完整可达。

官网 CSS 在 SPA 路由切换后仍会保留，新增展示规则必须受 `.studio-landing` 根约束，不能仅凭 `studio-*` 类名前缀假定隔离。传送到 body 的官网图片预览使用独立 `.website-art-preview`，并限定在公共弹窗内。官网定稿示意使用 `.benefit-direction`，不得复用真实导演助手的 `.studio-director`。

公开演示独立于已登录工作区。没有授权封面时展示真实片名和状态，没有文件预览时显示文件名、类型和预览入口，不能把官网样片或经营图表填入私人记录。

## 6. 两套工作台的任务交互

### 6.1 办公：发起、核对、交付

首页首屏提供任务输入、上传、有效默认智能体/模型/权限，附近展示本人最近会话与交付物。首页与会话共用草稿和发送流程；只有明确发送才创建任务，重复点击进入同一个真实会话。默认配置不可用时说明原因并提供选择入口，不显示可以发送却持续准备的假就绪状态。

会话按用户任务、回复、待确认、执行结果和交付文件呈现。历史会话打开后保持同一输入栏结构，模型和权限继续放在输入区；宽屏尽量保持底部操作一行，窄屏按可用宽度排布，不能让发送、停止或已选项不可达。

来源、执行状态与交付物分别可识别。宽屏可并排预览，窄屏按需展开；预览、下载、回到来源使用真实授权。Word、Excel、PPT 是后台发布的智能体、技能和工具，不在公共页面按助手名写专属流程。更多页面细则见[办公需求与设计](星桥办公/需求与设计.md)。

### 6.2 娱乐：由想法进入制作

娱乐首页引导用户选择创作方式，并提供进入「我的作品」的入口。作品库中的封面来自有权读取的已采用画面；无画面时用真实片名和轻量文字封面。作品头部集中返回、规格、导演与保存；八阶段导航保持一行，窄屏只在该栏横向滚动，不撑开页面。

作品内按“作品构想 → 剧本与场次 → 角色与场景 → 分镜设计 → 试做一镜 → 批量制作 → 剪辑与字幕 → 成片交付”组织上下文。阶段导航可检查其他内容，提交动作按真实前置条件校验。用户应知道本步要决定什么、已有内容是什么、还缺什么，以及下一步会产生什么；不能用一组未解释字段或空白审阅勾选代替流程。

| 阶段或操作       | 页面必须体现的交互                                                                                                                                                                                   |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 构想与原稿       | 已有剧本可粘贴，只有想法可让导演起草；直接带入作品构想，不要求用户先写完整剧本。空态提供起草和手工入口。                                                                                             |
| 参考资料         | 支持上传形象、移除与命名、选择个人库具体版本。发送前展示本次引用和来源；上传失败保留文字与已成功文件。图像理解、联网查询展示真实能力及不可用原因，联网由用户选择，处理后可展开说明与来源。           |
| 剧本与场次       | 桌面原稿与场次约 61:39，手机上下排列；目录与当前场次编辑分离。可选原文建场或关联到当前场次，排序保持场次、台词和镜头身份。忠于原文与允许改编是明确选择，不能静默切换。                               |
| AI 编辑          | 选段修改、单场修改共用编辑与对比流程。先展示冻结范围和要求，再生成待审建议；采用并保存才改正文。撤回只恢复本次采用，保留范围外后续编辑；重叠冲突提示重新选择。                                       |
| 方案审阅         | 显示原方案、当前工程、导演建议的实际差异，逐字段选择采用；名称采用镜号、场次、人物、台词和秒数，隐藏空技术字段。长文可展开，不整段显示 UUID、字典或内部范围对象。                                    |
| 角色、场景与声音 | 卡面呈现已采用设定和版本，长说明折叠，动作集中。试听、生成候选、预览、采用相互区分；使用真实声音与当前引用，不把候选到达当成已定稿。                                                                 |
| 分镜与候选       | 宽屏按左侧选镜、中间画面与候选、右侧详情组织，窄屏按选镜、预览、比较、详情阅读。点击候选只预览，采用才修改工程，支持换回。                                                                           |
| 试做与批量制作   | 先呈现范围、模型、镜头、台词及阻塞项，再确认提交。区分“输入参考图”与“新增参考画面”，零项不制造歧义。支持只补缺失、只处理失败；试做显示当前镜视频与配音的排队、执行、失败和核对状态，并提供任务入口。 |
| 剪辑与交付       | 时间线点镜定位当前编辑区，仅展开当前镜头；标题为镜号、场景和时长，完整动作展开阅读。裁剪、台词、字幕切镜不丢草稿，历史版本默认收起。导出绑定工程版本，成片可播放、下载并追溯。                       |

导演抽屉发送前说明本次安排，显示资料、补充要求、保存及提交状态；打开面板不自动发任务。建议完成后提供直接审阅入口。工具绑定过期提供显式修复操作，保留原指令和附件；不能自动改用另一个助手绕过权限或定制内容。

阶段确认位于相关内容之后。缺内容时按钮旁说明具体缺项并能定位；有待审方案时先审阅。空白剧本不先显示“我已审阅”，无场次也不强迫用户填写占位场次或调用 AI。确认成功才继续，保存失败或审阅期间内容变化不静默跳转。

具体制作规则、对象关系及未交付能力见[娱乐需求与设计](星桥娱乐/需求与设计.md)。这里的时间线呈现规则不表示专业拖动剪辑、口型同步或所有自动排时能力已完成。

### 制作过程页的布局约束

- 分镜工作区按扣除侧栏后的实际内容宽度适配：足够宽时使用 240px 目录、中央预览和 320px 检查器；不足时把检查器移入公共抽屉，窄内容区改为横向短选镜条。当前步骤与当前镜头自动进入各自目录的可见区，不带动整页跳动。
- 多栏状态共用随视口高度调整的工作区高度，顶部和底部对齐；目录、候选和检查器的正文各自在超出时滚动，中央画面按剩余空间等比缩放，采用操作始终留在候选标题旁。分镜顺序、镜头设定与画面/台词/参考素材页签固定在块内顶部，生成入口留在检查器底栏；手机抽屉采用相同规则。窄屏单栏保持自然高度，不强行等高。
- 目录只展示镜号、场景短名、缩略图、两行摘要与状态；完整描述在检查器编辑。新建、当前镜头操作、批量制作分组。画面、台词、参考素材分组编辑，切换布局继续编辑同一工程草稿。
- 正式预览保留素材比例并限制高度，缩略图独立裁切。音频控件在组件内部限制宽度；双候选在手机上上下比较。仅一个候选时使用紧凑条，采用按钮与候选标题相邻。
- `ExpandableText` 按真实溢出显示展开入口；`SelectionOption` 让短复选标题与可展开正文分离；`DurationField` 显示秒并保留毫秒精度。不得再把整段生成要求直接作为按钮或复选框标签。
- 批量范围选择允许自然换行，制作设置与任务记录分区；任务可筛选与分页。预检按需要处理、本次提交、已跳过分组，跳过项默认收起。交付空态按导出结果判断，不能被普通视频任务遮蔽。
- AI 编辑与个人素材制作使用公共固定底栏；长原文和失败详情在正文展开。公共弹窗完整错误在可滚动正文显示，底栏保留查看错误入口及操作，不被异常文本撑高。个人候选独立分页，当前采用项明确标记。
- 时间线在局部区域横向滚动并提供缩放，点击配音或字幕可定位本镜编辑。画面裁剪、配音、字幕分组，历史修订默认收起；这些呈现调整不代表新增拖动剪辑或自动排时能力。

### 6.3 两端共用的 AI 与异步反馈

三类作品目录使用“全部／快速视频／分镜作品／系列短剧”分类，继续复用公共工具栏、同高作品卡与置底分页；分类不改变侧栏 RBAC 层级。快速版输入与候选区在桌面等高，块标题和主要操作固定，窄屏顺序展示；模型能力不支持的配置隐藏或明确说明原因，不照搬参考产品的收费或功能入口。

系列短剧以“整剧总览／故事与分集／本剧设定／剧集制作／成片交付”组织上下文。分集编排宽屏采用目录、故事、助手三栏，使用公共 `ScrollPanel`；中等宽度将助手放在下方，手机先选集再编辑，不能压窄正文凑三栏。助手的范围、原文与建议必须可见，逐段采用；保存、确认故事、进入制作是不同动作。结构调整在公共弹窗中先预览，明确原工程与素材保留方式。单集顶部显示所属整剧与切集入口，历史工程明确只读，不展示软归档的内部占位集号。

娱乐侧栏首项为带房屋图标的「首页」，位于「创作工作台」分组上方。登录后的创作中心延续娱乐首页的暖色纸面、宋体标题及分镜与成片对照，深色外观随主题切换。首屏提供「查看我的作品」，下方用三张整卡说明快速创作、分镜创作、系列短剧各自的输入和产出，桌面并排，手机纵向排列。快速模式直接进入编辑器，分镜和系列进入独立创建页。标题和底部操作固定，正文依次填写故事设定与制作规格。系列的目标时长按每集计算。返回和切产品时保护整份未保存输入，提交中禁止重复创建或离开。创建成功后分别进入故事编辑或分集编排。「我的作品」负责查找历史作品和继续编辑，返回作品库时恢复筛选与页码。

- 普通答复、思考内容、工具执行、待确认与成果分开呈现；思考默认折叠，不把长篇 reasoning 当作普通导演或助手答复铺满页面。
- 工具确认必须显示本次动作、目标和参数。按当前会话及实际调用读取准备方案；读取失败可重试，不能只给泛化说明和一个“确认”按钮让用户盲批。技术对象可折叠查看，常用字段优先可读。
- 首次连接、排队、执行、需要确认、失败、中断与完成使用准确状态。停止对话、取消未提交任务、申请取消供应商任务分别说明效果；不能把取消申请当作已经取消。
- 受理未知保留待核对入口及原请求身份，不能因刷新或重试自动再次收费。处理失败保留输入和可用结果；已成功准备的资料在恢复时复用。任务完成不自动覆盖用户已采用内容。
- 长任务关闭页面后可恢复，任务入口能回到所属作品、镜头或台词。后台进度更新不跳走当前编辑位置，不盖住正文和操作。

## 7. 权限、无障碍与响应式

所有私有图片、视频封面、素材、文件、预览和下载都来自本人有权读取的数据。隐藏按钮只是呈现行为；直达 URL、伪造请求、产品切换和跨账号读取继续由服务端拒绝。权限撤销或账号变化后旧内容、旧请求和旧预览必须失效。只读账号仍能按权限查看，不显示可编辑假象。

| 视口          | 布局重点                                                                                   |
| ------------- | ------------------------------------------------------------------------------------------ |
| 390px         | 导航抽屉，官网纵向阅读，启动页娱乐在前；目录/当前编辑分离，按钮可换行，主操作与关闭可达。  |
| 768px         | 收起固定侧栏，优先当前正文或画面；详情、检查器和文件预览按需展开，不能沿用压缩的桌面多栏。 |
| 1280 / 1440px | 共享侧栏，管理列表完整操作列，娱乐多栏工作区、办公会话与交付可同屏；短列表仍分页置底。     |

页面不出现无意横向溢出；宽表、步骤栏和媒体时间线的必要横向滚动限定在有名称的局部区域。长中文、英文标识、错误、按钮和资源名均需测试。矮屏与手机软键盘不能使表单尾部、发送或底栏被覆盖。

键盘可访问菜单、页签、选镜、候选、表单和浮层；图标按钮提供名称，焦点清晰，弹窗有标题和焦点约束，关闭后归还焦点。移序必须提供前移/后移等替代操作，不能只依赖拖拽、悬停或精细点击。表单有标签和错误关联，状态变化采用适当的可读提示。

正文及必要操作文字按至少 4.5:1 对比度目标校验，禁用态之外的控件边界与焦点保持可辨。渐变检查常态、悬停和中间插值，不能只测端点。尊重减少动态偏好，动画不作为理解状态的唯一方式。响应式截图不能代替浏览器 200% 缩放、屏幕阅读器和跨浏览器验证。

## 8. 设计验收与证据边界

每次公共样式修改从真实页面入口走查，再检查组件内部；“页面没有横向溢出”不能替代下拉框内部输入、双层边框、焦点、选中值和滚动遮挡验收。四条模型配置是管理列表首个样板，真实短内容与长内容都要检查。

| 验收组     | 最低覆盖                                                                                                                        |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 列表       | 四条短表、多页、末行完整、分页置底与翻页回顶；直接按钮行为、默认切换/清除、检测中防重复；空数据和无匹配分别呈现。               |
| 表单与浮层 | 长文、资源选择、下拉搜索/清空/Esc、内部控件皮肤、保存失败保稿、校验定位、只读、危险确认、关闭保护与还焦；正文末项不被底栏覆盖。 |
| 产品与身份 | 办公和娱乐、浅色和深色、五类角色及“办公管理员兼娱乐创作者”往返切换；直达越权接口和跨账号媒体/文件拒绝。                         |
| 创作       | 只有想法起草、图片/库引用、真实能力不可用、方案对比、局部采用/撤回、任务未知受理、候选采用/换回、切镜保留草稿及竖屏预览关闭。   |
