# 星桥办公需求与设计

星桥办公帮助用户用自己的资料完成问答、分析、文档和演示等任务，并得到可核对来源、可预览下载、可继续修改的成果。它与星桥娱乐共用公共平台，工程和权限边界见[整体架构](../整体架构.md)；公共视觉、控件和响应式规则统一引用[页面设计](../页面设计.md)，代码与验收要求引用[开发规范](../开发规范.md)。

本文整理截至 2026-11-17 的产品需求和已落地设计，不新增独立 Office 引擎或专用账号体系。具体完成证据及仍待环境项见文末。

## 1. 用户目标与产品边界

| 使用者         | 主要目标                                       | 产品需要提供的结果                                         |
| -------------- | ---------------------------------------------- | ---------------------------------------------------------- |
| 办公用户       | 直接提问、上传资料、选择业务助手、查找已有工作 | 一次明确发送进入一个真实会话，资料与上下文保留，结果可追溯 |
| 办公管理员     | 让团队使用合适的知识、智能体、技能、工具和模型 | 可检查、试用、发布和停用本产品能力，管理普通成员与菜单     |
| 平台超级管理员 | 维护账号、角色、供应商凭据、扩展、存储与服务   | 公共配置可维护、敏感信息不下发、操作留审计                 |

Word、Excel、PPT、知识问答都是管理员发布的能力组合。用户在同一办公工作台使用它们；平台不按助手名字写专用分支，也不要求每个任务走固定向导。普通对话不强制进入技能程序。能力尚未配置或已被停用时显示真实状态，不用示例文件或虚构结果补位。

## 2. 从进入到交付的用户路径

通用和办公入口开放注册时，用户用邮箱验证码创建普通办公账号，首次获得 40 创作点，有效 30 天。用户名默认按邮箱生成，可用邮箱登录。接口、实施步骤和表结构见[整体架构中的注册设计](../整体架构.md#邮箱注册默认角色与首笔创作点)。

注册后可从「个人中心 → 我的会员与额度」核对首笔入账和到期日，并在「套餐与加购」比较试行方案。账户额度跨产品共用。见[个人会员、额度与套餐](../整体架构.md#个人会员额度与套餐)。

运营可在「平台管理 → 模型扣点价目」维护办公费率，试算平台与本人凭据承担的费用。办公会话的工具确认卡仍待接入。见[商品草稿、模型费率与任务报价](../整体架构.md#商品草稿模型费率与任务报价)。

后台可按用户办理开通、同档续期、赠送或补偿加额，获收款登记权限后也可核对线下实收。金额、有效期和预计可用余额先经预览确认。见[后台人工会员办理](../整体架构.md#后台人工会员办理)。

| 步骤     | 用户操作                                                | 页面反馈与系统行为                                                                       |
| -------- | ------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| 进入办公 | 从官网选择办公、从系统选择页进入，或打开原会话/文件链接 | 单办公资格直接到办公首页；双资格可切产品；登录后优先恢复有权访问的站内目标               |
| 描述任务 | 首页输入目标，按需上传文件或选择已发布智能体            | 首页与会话共用草稿、附件、模型、权限和发送方法；打开首页或“试用”只准备草稿，不自动提交   |
| 明确发送 | 使用有效默认值，必要时手动改目标设备、模型或权限        | 防重复提交；服务端校验产品、资源和模型，准备 DSH，成功后进入对应会话；失败保留可恢复输入 |
| 理解资料 | 查看回复、文件检查和知识引用；缺信息时补充              | 区分来源事实、模型建议和待确认项，未提供真实资料不自动使用演示业务数据                   |
| 确认执行 | 审阅方案、范围、输入和工具要求，回答补充问题            | 审批绑定当前请求与修订；取消不执行副作用；变更方案使旧确认失效                           |
| 查看进度 | 观察消息、工具状态和阶段结果，必要时中断                | 快照和事件合并，不重复消息或闪回输入选择；断开网页不等于取消任务；终止以真实状态为准     |
| 核对成果 | 打开引用、预览并下载真实文件                            | 展示来源、成果类型、执行/质量状态；不合格结果标草稿；预览和下载重新校验授权              |
| 继续工作 | 在原会话提出修改，或从历史、文件、最近成果回到工作      | 修订产生新成果版本，保留来源和前次结果；删除历史不假定所有独立成果已经物理删除           |

首屏服务于“我要完成什么”：任务输入、本人最近会话、本人最近交付物和有权使用的快捷入口。没有历史时显示空态；失败时显示重试原因。官网公开样表仅用于官网演示，私人首页必须来自真实授权数据。

## 3. 菜单与权限

默认菜单沿用服务端统一注册目录，侧栏只保留两级。办公首页通过品牌入口返回，不把每种文档类型变成固定菜单。

| 一级菜单   | 二级菜单                                                                     | 默认可见角色                     |
| ---------- | ---------------------------------------------------------------------------- | -------------------------------- |
| 办公工作台 | 智能对话、历史会话、我的文件、我的设备                                       | 办公用户、办公管理员、超管       |
| 能力管理   | 智能体、知识库、技能、工具、默认模型                                         | 办公管理员、超管                 |
| 产品管理   | 产品成员、菜单配置                                                           | 办公管理员、超管                 |
| 平台管理   | 平台总览、账号与角色、供应商与模型、扩展管理、设备运维、存储与服务、平台审计 | 超管                             |
| 个人中心   | 账号资料、账号安全、外观设置、个人模型                                       | 所有已登录角色；个人模型另需授权 |

账号与角色、供应商与模型、存储与服务可在同一页面组内切换相关视图，保留已有深链。登录、改密、OAuth、公开分享、文件预览和终端等是独立或上下文入口，不为凑菜单层级重复建立页面。

办公管理员可以管理本产品普通成员、菜单和能力发布，并从获授权配置选择办公默认模型；不能修改平台密钥、安装可执行扩展、授予管理员、禁用或删除全局账号。移除普通成员办公资格不影响其娱乐资格。其他角色授予的权限不能通过移除普通成员身份绕过。

菜单隐藏与权限撤销分开处理。服务端所有接口仍校验产品资格、功能权限及资源归属。具有“办公管理员＋娱乐创作者”的账号切到娱乐后只能创作和使用个人功能；办公管理权不能跨产品继承。菜单保存有修订冲突提示，恢复默认仅作用于选定产品。

## 4. 工作台、会话和模型

### 首页与输入栏

`/#/office` 是办公落点；智能对话和历史继续使用现有 `/#/workspace` 体系。首页输入与完整会话使用同一工作台用例，不维护第二套提交 API。打开页面不发消息，显式点击发送才创建执行请求。

服务端 Agent、目标设备、业务智能体、模型与权限集中在输入栏。默认模型来自当前账号可用配置，选择目录与真实 DSH 目录对齐；个人/平台同名连接保留可辨认来源，不能仅按显示名合并。手动选择和已有会话绑定保留；失效选择明确提示，不静默换供应商。推理等可选参数仅按所选模型能力显示。

### 历史与项目

会话按已有项目、设备、置顶和归档组织，支持搜索、继续对话、重命名、置顶、归档及删除。历史记录行末保留省略号菜单，适配鼠标、键盘和触屏；管理列表直接显示操作的规则不套用到历史侧栏。

删除须确认，运行任务未停止时拒绝删除。终止请求不重复提交，等待持久状态确认；迟到事件不能复活已删除会话。已有生成文件可独立保留，文件删除与存储回收另走授权和引用检查。

### 执行状态和恢复

消息、工具调用、用户问题、审批与成果使用同一会话时间线。订阅处理顺序、重复、断线和快照竞态；切会话或换账号后，旧响应不能清空当前选择或污染新草稿。等待审批与执行中分别展示，已经处理或过期的审批不能重复执行。

停止后保留已完成步骤；失败展示可关联的诊断及下一步。结果未知的副作用不自动重试，已完成请求通过收据返回。真实 DSH 缺失会话或失去运行所有权时明确报异常，不能只把按钮改成“空闲”表示已成功终止。

## 5. 能力管理与资料

| 能力   | 管理员操作                                                                  | 使用者体验及约束                                                   |
| ------ | --------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| 智能体 | 编辑说明、知识/素材/技能/工具关联，发布检查、试用、发布或取消发布、历史修订 | 只选已发布且有权使用的配置；试用准备草稿，不替用户发送             |
| 知识库 | 上传与关联资料、解析、索引配置、重建、失败重试、检索检查                    | 回答能回到原文来源；空库、损坏文件、索引未就绪分别说明，不编造引用 |
| 技能   | 导入、编辑匹配与输入输出、配置阶段、校验发布、查看版本                      | 普通指令与可配置阶段并存；确认、修订和证据要求不由提示词关闭       |
| 工具   | 选择来源实现、配置参数、启停、关联和校验                                    | Schema、冻结版本、权限与真实工具结果统一处理；凭据不随正文返回     |
| 模型   | 选择办公有效默认值；超管管理连接与能力，个人模型按授权管理                  | 显式选择可追溯，停用与撤权及时生效；只读检测无法证明生成质量       |

扩展安装与能力发布分权。工具实现可来自内置包、Node/Python 包、MCP stdio 或远程 MCP；运行安装、健康检查与生命周期仍由平台管理。工具摘要或外部 Schema 变化不能沿用不匹配的旧绑定直接执行。

默认示例是可编辑的数据包。初始化不覆盖用户定制，也不复活已删除示例；用户明确需要演示资料时才引用。知识解析与嵌入使用持久状态和受管后台处理，不阻塞请求或只在浏览器内保留进度。

## 6. 文件、成果和设备

### 文件与来源

“我的文件”提供本人授权文件的上传、筛选、分页、预览、下载与删除。会话附件、知识资料、智能体素材和生成成果具有各自来源及引用关系，同一个文件不因入口不同失去授权检查。

文件工作区保留目录、编码/大小限制、编辑保存、独立预览和下载。并发修改通过版本条件拒绝覆盖，未保存离开保留退出确认。上传失败、半成品清理和存储迁移有收据；不能将登录凭据附加到不可信外部下载地址。

### 可编辑成果

Office 工具实现在 `backend/toolkits/office`，经通用执行、确认、证据和成果服务接入。业务能力包括文档生成和修订、表格公式/重算/图表、演示中的原生可编辑元素、图片素材与实际渲染检查。原生结构、数据正确性与版式质量分别验证，不能用整页图片或仅解包成功替代可编辑成果。

会话显示成果来源、文件信息、质量状态及预览下载入口。宽屏可与对话并排查看，窄屏按需展开，使用公共预览组件。质量不合格保留诊断草稿，不能作为合格交付；修订产生新结果并保留关联。

办公首页最近成果使用 `GET /api/office/recent-deliverables?limit=4`，只返回本人可读办公会话的真实成果摘要与稳定会话/成果 ID；预览下载继续使用原成果授权接口。最近会话复用已有分页查询，禁止额外拼出无权限的文件直链。

### 设备与终端

“我的设备”只展示本人绑定设备及其在线、离线、准备/故障状态；全平台资产查看属于设备运维。服务端 Agent 不要求用户先连接实体电脑或手机。网页、桌面和手机继续通过已有协议使用会话。

设备工作区保留配对、连接、运行实例配置和诊断；受保护的必需引擎不能被普通卸载操作禁用。终端按权限、设备和工作区提供复用、尺寸调整、命名和关闭，切换标签或离开视图不应误杀仍在使用的会话。

## 7. 关键数据与接口归属

| 领域       | 保存/处理的业务对象                               | 当前实现归属                                                           |
| ---------- | ------------------------------------------------- | ---------------------------------------------------------------------- |
| 身份与菜单 | 账号角色、办公资格、产品成员、导航修订、撤权代际  | `backend/app/modules/identity`、`navigation`                           |
| 办公工作   | 项目、会话、消息、事件、分享、请求收据            | `modules/conversations`；前端 `views/workbench` 与对应 composables/API |
| 业务能力   | 智能体及资源版本、知识、技能运行、工具来源与配置  | `modules/agents`、`knowledge`、`skills`、`extensions`                  |
| 模型配置   | 供应商连接、配置修订、个人/平台可用目录、产品默认 | `modules/models`                                                       |
| 成果与文件 | 来源证据、成果版本、文件归属、存储及下载授权      | `modules/skills` 的通用证据服务、`files`、`storage`                    |

以上是领域职责说明，不创建第二套“办公业务总表”或独立可变会话副本。字段和请求响应以各领域 VO/DO、迁移和生产契约为准。所有新增接口遵循无版本路由；旧客户端入口由公共兼容映射保持。

## 8. 验收状态与继续开放项

2026-11-17 公共滚动面板调整：会话导航的标题/新建入口和会话成果的标题/收起入口移到滚动正文之外，历史行仍保留省略号菜单。全站滚动条使用同一主题皮肤，权限选择标题留在列表外。四档宽度与深浅主题的办公首页、会话成果预览/关闭及相关发送、权限场景共 11 项回归通过；历史会话取消删除、运行拒删、终止与删除后刷新回归通过。使用浏览器隔离合成接口，未重跑真实 DSH 或 Office 生成。证据在 `.superdsh-work/web-admin-validation/scroll-panels-20261117`。

已有实施记录支持：办公首页真实数据入口、基本管理页面、五角色登录和产品鉴权；会话默认模型、真实 DSH 消息与取消；知识、文件、存储及设备接口；可配置技能工具；Office 原生文件结构和 LibreOffice 渲染；新 Vue/FastAPI 启动与 Docker 生命周期。代表性 PPT 流程已验证中断、继续、确认、真实生成、预览下载及删除历史。

后续修改必须按改动重新验证，不能把这些历史专项累计成一次新的全量通过。产品回归最少覆盖：

1. 首页默认配置发送，重复点击只创建一次任务；缺模型或 Agent 准备失败能恢复，不丢输入。
2. 上传资料 → 来源引用 → 确认 → 成果预览下载 → 继续修订；无权与撤权读取被拒绝。
3. 历史打开、改名、置顶、归档、运行中终止、确认删除与刷新；换号/切产品不串草稿或订阅。
4. 智能体试用不自动发送；发布/停用、工具版本变化、知识索引失败与保存冲突显示正确。
5. “办公管理员＋娱乐创作者”往返切换，直接请求娱乐管理接口、平台凭据接口仍被拒绝；成员撤权不影响另一产品。
6. 按[页面设计](../页面设计.md)检查四档宽度、深浅主题、弹窗和下拉，保持输入栏、历史菜单、列表分页与文件预览可用。
