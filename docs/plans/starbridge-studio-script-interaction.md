# 剧本与场次：从字段录入到创作编排

本轮聚焦作品第二阶段及导演、方案审阅、进入角色设定的衔接。沿用八阶段导航、娱乐产品主题和 DSH，不改旧 `apps/admin`，不增加另一套对话执行器，也不把本次修改记为剪辑阶段交付。

## 观察与判断

在实际开发站点以只读方式查看用户作品。旧页面在空白剧本上方先放“还有内容需要补充”和审阅勾选，下一步按钮无法操作；场次全部展开成重复表单，导演入口位于长表单之后。打开导演后又是空指令框，未说明本次会产出什么、结果在哪里审阅。原文保护、自动保存和稳定身份已有实现，本轮保留并使其对用户可见。

原始截图和本轮采集的前后画面位于 `.superdsh-work/web-admin-validation/script-interaction`。用户实际作品未编辑、未发送导演指令。可访问性检查覆盖标签、目录按钮、键盘摘录、弹窗与焦点、窄屏溢出；不声称完成 WCAG 全项认证。

## 用户操作

1. **写故事。** 已有剧本可以直接粘贴；只有构想时，展示作品已有构想，并提供“让导演起草”。原稿有字数和阅读模式，编辑与阅读共用同一份内容。
2. **整理场次。** 桌面左右展示原稿与场次，窄屏上下排列。目录显示顺序、名称、摘要和镜头数量，点击后只编辑当前场次。可选取原文“建一场”，保留原文；上下移沿用稳定场次 ID，关联镜头、对白不改动。有镜头的场次不能直接删除，空场次移除仍要求确认。
3. **与导演协作。** 起草和整理均先打开带任务说明的抽屉，可补充要求，明确发送才保存并提交到作品 DSH 会话。显示保存、连接、提交、处理状态；抽屉关闭不丢草稿，离开作品取消轮询和启动等待。建议到达后可直接定位方案对比，采用前不修改工程；“选择无冲突建议”仅勾选，仍需明确采用。手工冲突保留原逐项覆盖确认。
4. **审阅后继续。** 剧本确认移到内容之后，空白时给“去写故事”，有待审方案时先引导审阅。确认弹窗展示真实原稿、场次、镜头数与改编模式，确认成功才进入角色设定。保存失败、审阅期间内容变化或仍有待审方案时不跳转。无场次时允许先确认原稿，后续仍可细化，避免强迫用户调用 AI 或填写无意义占位内容。

## 实现边界

- Vue 页面装配保留在 `StudioEditor`；原稿/场次展示在 `StudioScript`，阶段确认在 `StudioScriptReview`，导演交互在 `DirectorChat`。
- 场次操作、确认提交、导演会话分别进入领域 composable。场次摘要与导演任务语句使用纯方法；请求继续走原 API 模块。
- 沿用自动保存、工程修订、方案对比、阶段确认和 DSH 消息身份。没有新增数据库表、迁移或业务路由。
- 修正工作区原生控件样式覆盖 Element Plus 内部输入框的选择器，避免双层边框。布局间距、主题色、焦点和表单控件使用公共规范。

### 已落地的用户流程

- [x] 在故事原稿中选中文字，点击「AI 修改选段」。展示本次范围，支持润色、精简、对白调整快捷要求，也可填写自己的要求；打开面板不发送任务。
- [x] 「选中文字建一场」将稳定场次 ID 与正文范围关联。已有场次可选正文后点击「关联到当前场次」，之后「本场正文」与全文同步编辑，「AI 修改本场」使用同一建议流程。旧场次未关联时明确提示，不把摘要冒充本场正文。
- [x] 发送前保存当前工程，冻结正文范围、修订和操作号。模型只提交持久建议，正文暂不变化；完整结果到达后对照修改前与修改建议，建议可继续手工修改。
- [x] 「采用并保存」仅修改冻结范围，更新场次关联位置并保存工程修订。原有镜头、台词、视频和配音不会被自动重做；界面提醒核对关联分镜。
- [x] 「撤回本次采用」执行局部逆向修改，范围外后来保存的正文及其他工程修改保留。正文重叠修改、场次重新关联或无法可靠定位时禁止覆盖，提示重新选择。
- [x] 「放弃本次建议」关闭该请求，等待中的任务同时请求 DSH 中断；供应商或模型迟到的结果不能重新写入该建议。
- [x] 「AI 修改记录」恢复最近 30 条记录。采用前的建议和采用状态支持刷新恢复；采用后回看展示实际保存的手工调整版本。抽屉关闭保留当前页中的未发送要求和手工建议，切换范围及离开作品保护未提交草稿。

### 真实流程发现的接口与交互问题

- 导演工具原 Schema 未明确场次关联和原稿范围，模型把 `scene` 当作场次 ID，并把 `scriptRange` 写成时间码。明确 `sceneId`、可读地点与 Unicode 字符范围的契约，工具参数错误以可修正的安全字段提示传回 DSH；其他异常仍隐藏内部信息。内置方案工具沿用公共草稿机制，只保存待审建议，真正采用仍由用户决定。来源版本取唯一 manifest 元数据，旧冻结绑定、定制助手要求和历史保持不变。
- 工具确认原来没有展示本次参数。公共确认卡按实际调用标识读取有权限的准备方案，显示动作与参数；读取失败可重试且阻止盲目确认。导演与办公共用此实现，思考过程默认折叠。
- 方案对比不再暴露 UUID 和空技术字段；显示场次、镜号、角色、台词及秒数。长文复用公共展开组件，不额外套滚动区。角色卡片动作置于卡片底部，候选抽屉复用公共布局；阶段确认放在内容之后。
- 上述方案、角色和音色弹窗已在浅深主题、390 / 768 / 1280 / 1440px 验证；生产和测试 TypeScript、格式及定向浏览器回归通过。实际试听弹窗和候选采用入口已手工走通。
